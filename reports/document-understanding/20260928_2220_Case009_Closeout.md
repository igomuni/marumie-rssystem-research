## 1. Executive summary

**Case-009 research chain COMPLETE for the frozen baseline phase.** The chain followed Source Survey → Protocol Freeze → Row Selection → Ground Truth Freeze → First Frozen Benchmark, with each predecessor artifact unchanged after its own freeze.

The source-side result is not that “51 files” alone is a new layout mechanism. No evidence demonstrates that the 51-file package or file identity caused either failure.

## 5. Source/package findings and coverage

The official FY2024 CAO package is exactly **51 PDFs** (`0.pdf`–`50.pdf`), totaling 394 pages: `0.pdf` is cover/TOC and 50 are detail files. An exhaustive mechanical/first-page census found standard-ledger starts with `千円` and a file-opening division/organization scope in all 50 detail files. The census was exhaustive for links, first-page metadata/text/scope; visual first-page inspection covered files 0, 1, 16, 23, 34, 41, 42, and 50; and seven predeclared end→start boundary checks were sampled.

Thus grammar homogeneity is supported **at detail-file starts**, while heterogeneous context partitioning is confirmed by the distinct scope declarations and printed-prefix/organization families. It is not a claim that every page or every embedded box in all 50 files was visually classified.

## 11. Source-side property versus benchmark causality

The source-side property is confirmed: 51-file packaging, file-start scope declarations, and file identity as a context/provenance partition. The benchmark causality claim is **not demonstrated**: the target page is the opening page of locked `1.pdf`, so its local scope and unit are present without package order or a second PDF. Neither raw nor normalized output shows cross-file lookup, wrong-file identification, or absent file identity causing a miss.

The observed failures are instead candidate resolution (pdf.js/PyMuPDF) and target-page table/item association (Docling). This does not show packaging is irrelevant for another file or a package-wide task; it limits the conclusion to this frozen target.
